# ETS
# Event Ticketing System

An online platform for browsing, booking, and managing event tickets. Built with **Node.js, Express, MongoDB, and React**.

##Features
- Browse and search for events (Concerts, Sports, Theater)
- User authentication (Standard User, Event Organizer, Admin)
- Book, manage, and view ticket history
- Event management for organizers (Create, Edit, Delete events)
- Admin dashboard to manage users & events
